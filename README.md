# SignBridge App (v2.9.9)

A highly accessible, AI-powered Flutter application designed to bridge communication between Deaf and Hearing individuals through real-time WebRTC video calls, sign language gesture recognition, and speech-to-text translation.

## 🚀 Key Features (v2.9.9 Update)
- **Role-Based Accessibility Engine**: Adapts the UI dynamically based on the user's role (Deaf, Hearing, or Both).
- **Modern Neumorphic & Glassmorphic UI**: Premium aesthetic with full Light and Dark mode support.
- **WebRTC Peer-to-Peer Calling**: High-quality, low-latency video calls using Firebase Firestore for signaling.
- **AI-Powered Call Overlays**:
  - `CaptionOverlay`: Real-time glassmorphic subtitle bar.
  - `GifOverlay`: Pops up instantly to show sign language GIFs based on spoken words.
  - `AiStatusIndicator`: Live AI pipeline monitoring.
- **Local Persistence & History**: Powered by `Hive` for blazing fast offline storage of Settings, Recent Calls, and Translation History (with beautiful conversation cards).
- **Curated Learning Resources**: Built-in library of PDF materials for learning sign language.

## 🛠️ Tech Stack
- **Framework**: Flutter (Dart)
- **Backend / Signaling**: Firebase (Anonymous Auth & Firestore)
- **Realtime Comm**: `flutter_webrtc`
- **Local Database**: `hive` & `hive_flutter`
- **AI Subsystem**: `speech_to_text`, `flutter_tts`, `tflite_flutter` (stubbed for future model)

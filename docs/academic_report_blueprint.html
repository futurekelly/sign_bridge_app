1. Project Scope & Architecture

The SignBridge system is a bidirectional translation platform that integrates real-time WebRTC calling with on-device hand gesture recognition. It addresses the communication gap between Deaf users (who use Sign Language) and Hearing users (who use spoken language).

Feature Domain Technologies Involved Current Status
Direct Peer Dialing Firebase Auth, Cloud Firestore (Signaling) Completed (Phase 1)
Haptic Call Alerts Android Haptic Engine, Periodic Vibration Loop Completed (Phase 1)
Real-Time Video Stream WebRTC (Direct P2P Connection) Completed (Phase 2)
On-Device AI Pipeline MediaPipe Tasks Vision, TensorFlow Lite (TFLite) Completed (Phase 3)
Gesture Translation Flutter TTS (Text-to-Speech), WebRTC DataChannel Completed (Phase 3)
Visual Overlay Custom Paint (Coordinate Axis Re-alignment) Completed (Phase 3.1)
Academic Architecture Principle
We maintain a clean boundary: the Native Android (Kotlin) layer acts purely as a coordinate producer (extracting landmarks from WebRTC video frames), while the Dart (Flutter) AI pipeline maintains all platform-agnostic business logic (normalization, TFLite inference, stabilization, and TTS).

2. Implementing 2-Hand & 50+ Word TFLite Classifier

To expand vocabulary to 50+ common sign words and involve two hands, the pipeline needs modifications across both the Kotlin and Dart layers.

Step A: Modify Native Android Code (Kotlin)

Open android/app/src/main/kotlin/com/example/sign_bridge/HandLandmarkerHelper.kt and update the HandLandmarkerOptions to support 2 hands: 

// In HandLandmarkerHelper.kt:
val options = HandLandmarkerOptions.builder()
    .setBaseOptions(baseOptions)
    .setMinHandDetectionConfidence(0.5f)
    .setMinTrackingConfidence(0.5f)
    .setMinHandPresenceConfidence(0.5f)
    .setNumHands(2) // Change from 1 to 2
    .setRunningMode(RunningMode.LIVE_STREAM)
    .setResultListener { result, inputImage ->
        val landmarksList = result.landmarks() // Contains coordinates for detected hands
        val handsCount = landmarksList?.size ?: 0
        
        val payload = mutableMapOf()
        
        // Extract hand 0 (first hand)
        if (handsCount > 0) {
            payload["hand_0"] = landmarksList[0].mapIndexed { index, lm ->
                mapOf("id" to index, "x" to lm.x(), "y" to lm.y(), "z" to lm.z())
            }
        } else {
            payload["hand_0"] = emptyList>()
        }
        
        // Extract hand 1 (second hand)
        if (handsCount > 1) {
            payload["hand_1"] = landmarksList[1].mapIndexed { index, lm ->
                mapOf("id" to index, "x" to lm.x(), "y" to lm.y(), "z" to lm.z())
            }
        } else {
            payload["hand_1"] = emptyList>()
        }
        
        onLandmarksDetected?.invoke(payload)
    }
    .build()

Step B: Update Dart Input Extraction

In Dart (lib/services/ai/inference_manager.dart), change the input normalization to expect two hands. If only one hand is detected, pad the second hand with zeros: 

// Target: 42 landmarks total (21 per hand) * 3 coordinates = 126 input features
List normalizeDualLandmarks(Map> hands) {
  List features = [];
  
  // Normalize Hand 0
  if (hands['hand_0'] != null && hands['hand_0']!.isNotEmpty) {
    features.addAll(_normalizeSingleHand(hands['hand_0']!));
  } else {
    features.addAll(List.filled(63, 0.0)); // Zero padding
  }
  
  // Normalize Hand 1
  if (hands['hand_1'] != null && hands['hand_1']!.isNotEmpty) {
    features.addAll(_normalizeSingleHand(hands['hand_1']!));
  } else {
    features.addAll(List.filled(63, 0.0)); // Zero padding
  }
  
  return features; // Exactly 126 features
}

Step C: Python Training Script for 50+ Vocabulary Words

Use the script below to train your custom 126-input classifier using a simple Multi-Layer Perceptron (MLP) model. Convert it directly to .tflite: 

import numpy as np
import tensorflow as tf
from tensorflow.keras import layers, models

# 1. Load your collected landmark dataset (126 features per row)
# X_train: numpy array of shape (N, 126)
# y_train: numpy array of shape (N, 50) - one-hot encoded labels
X_train = np.load('X_train.npy')
y_train = np.load('y_train.npy')

# 2. Build the Classifier MLP Model
model = models.Sequential([
    layers.Input(shape=(126,)),
    layers.Dense(256, activation='relu'),
    layers.Dropout(0.3),
    layers.Dense(128, activation='relu'),
    layers.Dropout(0.2),
    layers.Dense(64, activation='relu'),
    # 50 outputs for your classes
    layers.Dense(50, activation='softmax')
])

model.compile(optimizer='adam',
              loss='categorical_crossentropy',
              metrics=['accuracy'])

# 3. Train the model
model.fit(X_train, y_train, epochs=150, batch_size=32, validation_split=0.2)

# 4. Save and Convert to TensorFlow Lite
converter = tf.lite.TFLiteConverter.from_keras_model(model)
converter.optimizations = [tf.lite.Optimize.DEFAULT] # Quantization for mobile speed
tflite_model = converter.convert()

with open('gesture_model_v2.tflite', 'wb') as f:
    f.write(tflite_model)
print("Expanded TFLite Model Compiled Successfully!")
